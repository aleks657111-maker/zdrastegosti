# Design

<!-- impeccable:design-schema 1 -->

## World

«Штамп доверия»: дерзкая крупная типографика на насыщенном зелёно-коричневом фоне, репутация (рейтинг, награда, отзывы) подана как наклеенные бумажные стикеры и печати под небольшим углом — а не как мелкий бейдж внизу страницы. Адаптация референса пользователя ("Fresh Meat Market") под кафе: сохранены дерзость масштаба и контраст стикеров, убрана мясная иконография. Палитра по запросу пользователя переведена на зелёный/коричневый/белый (2026-09-06).

## Palette

- `--black` #1c130d — тёмно-коричневый (почти чёрный), фон трастовой секции и футера
- `--red` #2f6b45 — основной насыщенный зелёный (hero, секция удобств, кнопки, акценты)
- `--red-deep` #3d2a1c — глубокий коричневый (нижняя часть hero-градиента, фон секции удобств)
- `--red-bright` #4f9d68 — яркий зелёный текст на тёмном фоне (проценты доверия, ссылки на hover)
- `--red-hover` #1f4a30 — тёмно-зелёный для hover-состояния сплошных кнопок (сохраняет контраст с белым текстом)
- `--cream` #fbf8f3 / `--cream-2` #f3ede3 — белый/почти белый, основной фон читаемых секций и стикеров
- `--ink` #241a14 — тёмно-коричневый текст на белом фоне
- `--gold` #b9825a — тёплый карамельно-коричневый акцент наград и звёзд рейтинга

Стратегия — Committed: один насыщенный зелёный несёт 30–60% поверхности (hero, amenities), белый служит бумажной паузой между насыщенными блоками (меню, контакты), коричневый — вторым тёмным тоном (трастовая секция, футер, глубина hero-градиента). Переменные сохранили старые имена (`--red`, `--red-deep` и т.д.) — это исторические названия ролей в системе, не буквальный цвет; при дальнейших правках ориентироваться на роль, а не на имя.

## Type

- Display: **Unbounded** (500/700/900) — заголовки, крупные цифры, кнопки-стикеры. Выбран за индустриальный «штамповый» характер и поддержку кириллицы.
- Text: **Manrope** (400–800) — весь остальной текст, кнопки, метаданные.
- Заголовок hero: clamp(3rem, 12vw, 8.2rem), вторая строка — контурная (text-stroke, заливка transparent).

## Components

- `.sticker` — кремовая/золотая карточка с лёгким поворотом (±3–4deg), используется для рейтинга и числа отзывов.
- `.btn-solid` / `.btn-outline` / `.btn-ghost` — пилюли; sold использует `--red` → `--red-hover` на hover (контраст с кремовым текстом сохранён).
- `.ticket` — пунктирная «билетная» плашка для удобств (амenities), не типовая icon-карточка.
- `.stamp-plate` / `.award-ring` — круглые «печати» с SVG-искажением края (`feDisplacementMap`, filter `#stampEdge`) для контактов и награды.
- `.menu-group` — строчный список блюд с точечным разделителем вместо фотокарточек (фотографий блюд у пользователя нет — решение через типографику).
- Зерно/грейн на hero — SVG `feTurbulence` (filter `#grain`), не растровая текстура.

## Motion

Один сигнальный приём: секции ниже первого экрана появляются через `opacity+translateY` (класс `.pending` → снят при пересечении вьюпорта, `IntersectionObserver`). Контент по умолчанию видим (progressive enhancement) — анимация не может оставить блок пустым при отключённом JS или уменьшенном движении (`prefers-reduced-motion`).

## Responsive

Mobile-first проверено на 390px: бургер-меню (fixed, тёмный фон), кнопка телефона на very small экранах (≤460px) сворачивается до иконки (текст скрыт, `aria-label` сохраняет доступность). Устранено горизонтальное переполнение шапки на узких экранах.

## Known constraints

- Реальных фотографий блюд/интерьера нет — визуальный язык намеренно типографский/текстурный, а не фото-карточный. При появлении реальных фото у пользователя их можно добавить в `.menu-group` без изменения системы.
- Данные (рейтинг, отзывы, меню, удобства) взяты с Яндекс.Карт на 2026-09-06 — при обновлении сверяться с первоисточником.
